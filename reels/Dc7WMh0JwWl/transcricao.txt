If you're doing any local LLM inference, you should give DeepSea Karnas a try. It is the only open source direct competition to the interface that Cursor and Codex share. It loads up in a website locally. It works great so far in all my testing. And there's a TUI for the terminal built for DeepSea Karnas already. It's called Marty, M-A-R-T-T-Y. And works great as well, love it. I've forked both and removed all the telemetry so that I'm not getting tracked or anything like that. But you can fork it and remove the telemetry and then you've got yourself some really good, really powerful local harnesses to play with.
