If you guys want to get better front-end designs with Cloud Code, here are five plugins you need to install right now. The first is Taste Skill that pulls real design taste from premium references so your UI stops looking crappy and vibe-coded. The second is the Web Design Guideline Skill. It'll audit your code against Vercelles' latest design rules and flag any weak points before you actually ship anything. The third is Awesome Design. It'll hand your AI a full design system pulled from top quality websites with colors, typography, spacing, buttons, everything all done for you. The fourth is Image to Code, which will turn any design reference into actual usable code without losing any of those details. And the fifth is Playwright CLI. This gives Cloud the power to open up a browser, screenshot what it just built, and even catch crappy outputs and errors before you see them.
